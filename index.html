Turn a codebase into a narrated video you can trust

codebase-video is a plugin for Claude Code. Claude reads your code and writes down what it learned; a second Claude checks every statement against the code. Only then is the video made, with the real code and diagrams on screen.

This five-minute video was made by the plugin, about the plugin's own repository. The example frames in it come from a longer video the plugin made of the public FCQRS library.

Install

You need Claude Code, Node.js 18 or later, ffmpeg, and Google Chrome or Chromium. Then, inside Claude Code:

/plugin marketplace add OnurGumus/codebase-video
/plugin install codebase-video@codebase-video

Go to the repository you want a video about and type:

/codebase-video

The first run downloads the voice and a browser driver, about 800 MB, once.

What to know

  • The video is made on your computer. The voice, the drawing and the encoding run locally; nothing is uploaded. Your code is read by Claude Code, as in any Claude Code session.
  • Most of the work is checking. One agent writes a teaching document that points to the file and lines behind every statement; fresh agents check it, the script and every scene against the code.
  • Three lengths: short (3 to 5 minutes), tour (6 to 10) and deep (20 to 28).
