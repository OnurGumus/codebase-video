# Share it on GitHub

**You get** a video that plays inside a README or an issue.

## Steps

1. **Ask for a short video** (3 to 5 minutes). GitHub plays a video only up to 10 MB, so a short video is kept under
   that: the engine checks the size and, if needed, encodes the picture again to fit.
2. **Ask for captions in the video.** GitHub's player starts muted and cannot load the separate captions file, so
   the words are drawn at the bottom of the picture as they are spoken.
3. **Attach it.** Edit the README on github.com and drag `out/<name>.mp4` into the editor. A link to a file in the
   repository does not play.

The first frame of a short video is drawn as its thumbnail: the title, a red border, a play button and the length.

## Tips

- A longer video does not fit in 10 MB. Host it elsewhere (a release asset, a project page, a video site) and link
  to it. Ask if you want the thumbnail on a longer video too.
- `CODEBASE_VIDEO_SHORT_MAX_MB` changes the 10 MB limit.
